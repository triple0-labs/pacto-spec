# Pacto documentation

Pacto is a **spec-driven development (SDD)** CLI: markdown plan slices under `.pacto/plans/`, explicit states, and evidence-backed `pacto status` — without tying you to a single editor or model.

Use this page to navigate product docs. For install, badges, and the end-to-end command loop diagram, see the [project README](../README.md).
